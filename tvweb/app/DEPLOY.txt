========================================
TV 管理后台 - 部署清单
========================================

需要上传到服务器的文件：

主目录文件：
  ✓ index.html
  ✓ app.js
  ✓ cookie.html
  ✓ cookie.js
  ✓ install.php
  ✓ README.md

lib/ 目录（第三方库）：
  ✓ lib/vue.js
  ✓ lib/element-ui.js
  ✓ lib/element-ui.css
  ✓ lib/axios.min.js

api/ 目录（后端接口）：
  ✓ api/config.php
  ✓ api/login.php
  ✓ api/login_safe.php
  ✓ api/users.php
  ✓ api/announcements.php
  ✓ api/banners.php
  ✓ api/config_api.php
  ✓ api/video_sources.php
  ✓ api/api_get_cookie.php
  ✓ api/api_update_cookie.php
  ✓ api/banner_click.php
  ✓ api/banner_json.php
  ✓ api/video_sources_json.php

========================================
部署步骤：
========================================

1. 上传所有文件到服务器 /app/ 目录

2. 修改 api/config.php 中的数据库配置：
   - DB_HOST
   - DB_NAME
   - DB_USER
   - DB_PASS

3. 访问 https://你的域名/app/install.php
   初始化数据库

4. 访问 https://你的域名/app/index.html
   使用 admin/admin123 登录

5. 登录后立即修改默认密码

6. 删除 install.php（可选，提高安全性）

========================================
注意事项：
========================================

- 确保 PHP 版本 >= 7.0
- 确保 MySQL 版本 >= 5.7
- 确保 PDO 扩展已启用
- 文件权限：PHP 文件 644，目录 755
- 如遇 403 错误，系统会自动尝试多种登录方法

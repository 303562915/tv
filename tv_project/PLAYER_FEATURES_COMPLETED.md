## 🚀 使用方式

### 手势操作
```
左右滑动 → 调整播放进度
左侧上下滑动 → 调整屏幕亮度
右侧上下滑动 → 调整系统音量
双击 → 播放/暂停
长按 → 2倍速快进
单击 → 显示/隐藏控制栏
```

### 菜单功能
```
点击菜单按钮 → 打开侧滑菜单
选择画面比例 → 立即应用
拖动倍速滑动条 → 精确调节播放速度
点击快速倍速按钮 → 快速切换常用倍速
开关片头片尾跳过 → 自动跳过片头/片尾
```

### 锁定功能
```
点击左侧锁定按钮 → 锁定屏幕
锁定后 → 隐藏所有控制栏，禁用手势
再次点击锁定按钮 → 解锁
```

## 📊 技术实现

### 网速监控
- 使用 `TrafficStats` API 获取网络流量
- 每秒计算一次网速
- 使用 Kotlin Flow 实时推送数据

### 手势识别
- 使用 `GestureDetector` 处理手势
- 区分左右区域和上下滑动
- 实时计算调整值并应用

### 画面比例
- 使用 ExoPlayer 的 `AspectRatioFrameLayout`
- 支持5种常用比例模式
- 使用 SharedPreferences 保存用户偏好

### 片头片尾跳过
- 基于时间的简单检测算法
- 可配置片头片尾时长
- 使用 SharedPreferences 保存设置

## 🎯 代码特点

1. **Kotlin 风格** - 完全使用 Kotlin 编写，符合 Android 现代开发规范
2. **协程支持** - 使用 Kotlin Coroutines 处理异步任务

## 📝 注意事项

1. 需要在 `build.gradle` 中添加 Material Design 依赖
2. 需要在 `AndroidManifest.xml` 中添加必要的权限（网络、存储等）
3. 截屏功能需要 Android 8.0+ 系统
4. 投屏功能需要安装第三方投屏应用

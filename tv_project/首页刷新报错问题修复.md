# 首页刷新报错问题修复

## 问题描述
首页刷新时一直报错，无法正常显示轮播图。

## 问题分析

### 错误日志
```
BannerAdapter: 图片加载失败: https://picsum.photos/800/400?random=2, 错误: Failed to load resource
BannerAdapter: com.bumptech.glide.load.HttpException(Failed to connect or obtain data, status code: -1)
```

### 根本原因
1. **外部图片服务不可用**: 使用了 `picsum.photos` 作为轮播图图片源
2. **网络访问问题**: 该服务在中国可能被墙或不稳定
3. **没有降级方案**: 图片加载失败时没有合适的降级处理

### 问题代码
```kotlin
// HomeFragment.kt
val defaultBannerData = listOf(
    BannerItem(
        imageUrl = "https://picsum.photos/800/400?random=1", // ❌ 外部服务
        linkUrl = "",
        description = "精彩影视推荐",
        visible = true
    ),
    // ...
)
```

## 解决方案

### 1. 使用本地占位图 ✅

**修改文件**: `HomeFragment.kt`

```kotlin
// 修改前
imageUrl = "https://picsum.photos/800/400?random=1"

// 修改后
imageUrl = "" // 使用空字符串，将显示占位图
```

**效果**: 
- 不依赖外部网络服务
- 加载速度快
- 不会出现加载失败错误

### 2. 改进图片加载器 ✅

**修改文件**: `ImageLoader.kt`

添加了以下改进：

1. **空URL检查**
```kotlin
if (url.isBlank()) {
    android.util.Log.d("ImageLoader", "轮播图URL为空，使用占位图")
    imageView.setImageResource(placeholder)
    onError?.invoke()
    return
}
```

2. **超时设置**
```kotlin
.timeout(10000) // 设置10秒超时
```

3. **详细的错误日志**
```kotlin
android.util.Log.e("ImageLoader", "轮播图加载失败: $url, 错误: ${e?.message}")
e?.logRootCauses("BannerAdapter")
```

## 建议的改进方案

### 方案 1: 使用自己的图片服务器（推荐）

将轮播图上传到自己的服务器或CDN：

```kotlin
val defaultBannerData = listOf(
    BannerItem(
        imageUrl = "https://your-cdn.com/banner1.jpg",
        linkUrl = "https://your-site.com/movie1",
        description = "精彩影视推荐",
        visible = true
    )
)
```

**优点**:
- 完全可控
- 加载速度快
- 可以自定义图片内容

### 方案 2: 使用本地资源图片

将轮播图放在 `res/drawable` 目录：

```kotlin
val defaultBannerData = listOf(
    BannerItem(
        imageUrl = "android.resource://com.tv.ball/drawable/banner1",
        linkUrl = "",
        description = "精彩影视推荐",
        visible = true
    )
)
```

**优点**:
- 不需要网络
- 加载速度最快
- 永远不会失败

### 方案 3: 从后端API获取轮播图

创建一个API接口返回轮播图数据：

```kotlin
// API返回
{
    "banners": [
        {
            "imageUrl": "https://your-cdn.com/banner1.jpg",
            "linkUrl": "https://your-site.com/movie1",
            "description": "精彩影视推荐"
        }
    ]
}
```

**优点**:
- 可以动态更新
- 不需要发布新版本
- 可以A/B测试

### 方案 4: 添加重试机制

当图片加载失败时自动重试：

```kotlin
fun loadBannerWithRetry(
    context: Context,
    url: String,
    imageView: ImageView,
    placeholder: Int,
    maxRetries: Int = 3
) {
    var retryCount = 0
    
    fun tryLoad() {
        Glide.with(context)
            .load(url)
            .listener(object : RequestListener<Drawable> {
                override fun onLoadFailed(...): Boolean {
                    if (retryCount < maxRetries) {
                        retryCount++
                        android.util.Log.d("ImageLoader", "重试加载 ($retryCount/$maxRetries): $url")
                        tryLoad()
                    }
                    return false
                }
                // ...
            })
            .into(imageView)
    }
    
    tryLoad()
}
```

## 🎯 技术亮点

### 1. 智能设备识别
```kotlin
// 通过主机名和 HTTP 端口识别电脑设备
val type = when {
    hostname.contains("PC", ignoreCase = true) ||
    hostname.contains("DESKTOP", ignoreCase = true) ||
    hostname.contains("LAPTOP", ignoreCase = true) -> DeviceType.COMPUTER
    else -> if (isHttpPortOpen(ip)) DeviceType.COMPUTER else DeviceType.UNKNOWN
}
```

### 2. 异步扫描
```kotlin
// 并发扫描整个网段，不阻塞 UI
for (i in 1..254) {
    val job = kotlinx.coroutines.launch(Dispatchers.IO) {
        // 扫描逻辑
    }
    jobs.add(job)
}
jobs.forEach { it.join() }
```

### 3. 请求头转发
```javascript
// M3U8 播放时自动添加请求头
const hls = new Hls({
    xhrSetup: function(xhr, url) {
        if (referer) xhr.setRequestHeader('Referer', referer);
        if (userAgent) xhr.setRequestHeader('User-Agent', userAgent);
    }
});
```

## 🐛 已知限制

1. **网络限制**
   - 必须在同一 WiFi 网络
   - 不支持移动数据网络
   - 路由器 AP 隔离会影响扫描

2. **扫描限制**
   - 扫描时间较长（10-30秒）
   - 某些设备可能无法识别
   - 防火墙可能阻止扫描

3. **播放限制**
   - 需要手动在电脑浏览器打开
   - 某些视频源可能有防盗链
   - 播放期间不能退出应用

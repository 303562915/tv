### 1. 爱奇艺源配置 ✅
- **URL**: `https://iqiyizyapi.com/api.php/provide/vod/?ac=videolist&t={category}&pg={page}`
- **类型**: API (JSON格式)

### 2. 可可影视源配置 ✅
- **URL**: `https://103.194.185.51:51120/channel/{category}.html`
- **类型**: WEB (HTML解析)
- **特点**: 
  - 使用频道页结构 (`/channel/1.html` 电影, `/channel/2.html` 电视剧)
  - 支持多线路播放
  - 剧集线路和剧集分开显示

## 注意事项

1. **可可影视IP地址**: 使用的是 `https://103.194.185.51:51120`，如果无法访问可能需要更换域名
2. **SSL证书**: IP地址可能有SSL证书问题，建议在应用中配置忽略SSL验证（仅用于测试）
3. **分页**: 可可影视的频道页不支持分页，显示的是固定内容
4. **日志**: 所有解析都有详细的日志输出，可以通过 `adb logcat` 查看

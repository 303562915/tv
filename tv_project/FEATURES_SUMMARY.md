## 技术亮点

### 1. 架构设计
- **MVVM架构**：ViewModel + StateFlow 实现响应式UI
- **依赖注入**：使用Hilt进行依赖管理
- **模块化设计**：播放器、菜单、对话框等组件独立封装

### 2. 用户体验
- **流畅动画**：控制栏显示/隐藏使用淡入淡出动画
- **实时反馈**：所有操作都有Toast提示
- **状态保存**：播放进度、播放模式等状态持久化
- **错误处理**：播放失败时提供多种解决方案

### 3. 性能优化
- **异步加载**：缩略图异步加载，不阻塞UI
- **内存管理**：及时释放资源，避免内存泄漏
- **懒加载**：按需初始化组件

### 4. 兼容性
- **API兼容**：支持Android 5.0+
- **屏幕适配**：支持横竖屏切换
- **异常处理**：优雅处理各种异常情况

## 使用说明

### 访问本地视频
1. 打开应用，进入"设置"页面
2. 点击"本地视频"图标（现在使用更明显的offline图标）
3. 授予存储权限
4. 选择视频文件夹
5. 点击视频开始播放

### 查看视频信息
**方法1**：点击播放器菜单 → 选择"视频信息"
**方法2**：点击播放器界面的清晰度按钮（如"1080p"）

### 设置重复播放
1. 点击播放器菜单按钮
2. 在"重复播放"区域选择模式：
   - 关闭：播放完毕后停止
   - 单集循环：当前视频循环播放
   - 列表循环：播放列表循环播放

### 调整画面比例
1. 点击播放器菜单按钮
2. 在"画面比例"区域选择：
   - 自适应：根据视频尺寸自动调整
   - 16:9：固定16:9比例
   - 4:3：固定4:3比例
   - 铺满：铺满整个屏幕
   - 放大：放大裁剪

### 精确调节倍速
1. 点击播放器菜单按钮
2. 使用滑动条精确调节（0.5x - 2.0x）
3. 或点击快捷按钮（0.5x/0.75x/1.0x/1.25x/1.5x/2.0x）

## 已知问题

1. **缩略图API弃用**
   - 当前使用的 `MediaStore.Video.Thumbnails.getThumbnail()` 在 API 29 已弃用
   - 建议后续升级为 `ThumbnailUtils.createVideoThumbnail()` 或 `ContentResolver.loadThumbnail()`

2. **视频编码信息**
   - 当前视频编码、码率、帧率等信息为占位数据
   - 需要从ExoPlayer获取实际的媒体信息

3. **文件大小**
   - 网络视频无法获取文件大小
   - 本地视频可以通过File API获取

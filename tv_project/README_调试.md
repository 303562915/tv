## 如何使用

### 方法 1: 使用 PowerShell 调试脚本（推荐）

1. 打开 PowerShell
2. 进入项目目录：
   ```powershell
   cd C:\Users\s30356\Desktop\trae\tv
   ```
3. 运行调试脚本：
   ```powershell
   .\debug_player.ps1
   ```
4. 在手机上打开应用并尝试播放视频
5. 观察 PowerShell 窗口中的日志：
   - 🔴 **红色** = 错误（Error/Exception/Failed）
   - 🟡 **黄色** = 警告（Warning/Timeout）
   - 🟢 **绿色** = 成功（Success/Ready/Playing）

### 方法 2: 手动查看日志

```powershell
# 清空旧日志
adb logcat -c

# 实时查看日志（过滤关键信息）
adb logcat | Select-String -Pattern "tv.ball|ExoPlayer|VideoPlayer|Error|Exception"
```

### 方法 3: 保存日志到文件

```powershell
# 清空旧日志
adb logcat -c

# 在手机上播放视频...

# 保存日志到文件
adb logcat -d > player_log.txt

# 查看日志文件
notepad player_log.txt
```

## 常见问题排查

### 问题 1: 网络连接超时
**日志特征**:
```
播放错误: 网络连接超时
错误码: 2001
```

**解决方案**:
1. 检查手机网络连接
2. 尝试切换 WiFi/移动数据
3. 检查视频源是否可访问

### 问题 2: HTTP 状态错误
**日志特征**:
```
播放错误: HTTP状态错误
错误码: 2004
```

**解决方案**:
1. 视频链接可能已失效
2. 检查是否需要特殊的请求头
3. 尝试其他视频源

### 问题 3: 解析失败
**日志特征**:
```
播放错误: 清单文件格式错误
错误码: 3001
```

**解决方案**:
1. M3U8 文件可能损坏
2. 尝试其他视频格式
3. 检查网络稳定性

### 问题 4: 解码错误
**日志特征**:
```
播放错误: 解码器初始化失败
错误码: 4001
```

**解决方案**:
1. 视频编码格式可能不支持
2. 尝试降低视频质量
3. 检查设备硬件支持

### 错误码对照表
- `2001` - 网络连接超时
- `2002` - 网络连接失败
- `2003` - 无效的HTTP内容类型
- `2004` - HTTP状态错误
- `2005` - 文件未找到
- `3001` - 清单文件格式错误
- `3002` - 容器格式错误
- `4001` - 解码器初始化失败
- `4002` - 解码失败

更多错误码请参考 ExoPlayer 官方文档。

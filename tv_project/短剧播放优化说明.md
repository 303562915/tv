# 短剧播放优化 - 预加载和无缝切换

## 问题描述

之前的短剧播放存在以下问题：
1. **播放快结束时没有提前缓存下一集**
2. **播放结束后才开始加载下一集，导致卡顿**
3. **跳转到下一集时可能重复触发**
4. **没有后台预加载机制**

## 解决方案

### 1. 启用预加载机制

#### 预加载触发时机
- 在视频播放到**剩余10秒**时自动触发预加载
- 通过 `checkAndPreloadNextEpisode()` 方法监控播放进度
- 使用 `hasTriggeredPreload` 标志避免重复触发

#### 预加载流程
```kotlin
// 在 updateProgress() 中每秒检查
checkAndPreloadNextEpisode(position, duration)

// 当剩余时间 <= 10秒时触发
if (remainingSeconds <= preloadThresholdSeconds && remainingSeconds > 0) {
    if (isShortDrama && shortDramaManager.hasNextEpisode()) {
        hasTriggeredPreload = true
        preloadNextShortDramaEpisode()  // 启用预加载
    }
}
```

### 2. 后台播放器预缓冲

#### 后台播放器的作用
- 在当前视频播放时，后台创建第二个播放器
- 提前获取下一集的播放地址
- 开始缓冲下一集的视频内容
- 播放器设置为静音、不自动播放

#### 后台播放器配置
```kotlin
backgroundPlayer = ExoPlayer.Builder(this)
    .setLoadControl(loadControl)
    .build()
    .apply {
        playWhenReady = false  // 不自动播放，只缓冲
        volume = 0f  // 静音
    }
```

#### 缓冲策略
- 最小缓冲：15秒
- 最大缓冲：120秒
- 支持 HLS (m3u8) 和普通视频格式

### 3. 智能URL预加载

#### URL获取优化
```kotlin
private fun preloadNextShortDramaEpisode() {
    // 获取下一集信息（不改变当前索引）
    val nextEpisodeIndex = shortDramaManager.getCurrentEpisodeIndex() + 1
    val nextEpisode = shortDramaManager.getEpisodeAt(nextEpisodeIndex)
    
    // 如果URL为空，后台获取
    if (nextEpisode.url.isEmpty() && nextEpisode.videoId.isNotEmpty()) {
        val url = fetchShortDramaVideoUrl(nextEpisode.videoId)
        nextEpisode.url = url
        preloadedNextEpisodeUrl = url
    }
    
    // 创建后台播放器并开始缓冲
    prepareBackgroundPlayer(videoUrl)
}
```

### 4. 无缝播放切换

#### 播放下一集时的优化
```kotlin
private fun playShortDramaEpisode(episode: ShortDramaEpisode) {
    // 检查是否有预加载的URL
    if (preloadedNextEpisodeUrl != null && preloadedNextEpisodeUrl!!.isNotEmpty()) {
        android.util.Log.d("VideoPlayer", "✅ 使用预加载的URL")
        episode.url = preloadedNextEpisodeUrl!!
        preloadedNextEpisodeUrl = null
    }
    
    // 如果URL已经存在，直接播放（无需等待）
    if (episode.url.isNotEmpty()) {
        viewModel.loadVideo(...)
    }
}
```

### 5. 用户体验优化

#### 倒计时提示
- 剩余5秒时显示"5秒后播放下一集"按钮
- 用户可以点击立即播放
- 自动倒计时，到0时自动播放

#### 避免重复触发
- 使用 `hasTriggeredPreload` 标志
- 使用 `isPreloadingNextEpisode` 标志
- 播放结束后重置所有标志

## 技术细节

### ShortDramaManager 新增方法

```kotlin
// 获取下一集信息（不改变当前索引）
fun getNextEpisode(): ShortDramaEpisode?

// 移动到下一集（更新索引）
fun moveToNextEpisode()

// 获取当前剧集
fun getCurrentEpisode(): ShortDramaEpisode?
```

### 状态管理

```kotlin
// 预加载相关状态
private var isPreloadingNextEpisode = false  // 是否正在预加载
private var preloadedNextEpisodeUrl: String? = null  // 预加载的URL
private var hasTriggeredPreload = false  // 是否已触发预加载
private val preloadThresholdSeconds = 10  // 提前10秒开始预加载

// 后台播放器
private var backgroundPlayer: ExoPlayer? = null
private var isBackgroundPlayerReady = false
```

### 生命周期管理

```kotlin
// 播放结束时
override fun onEnded() {
    // 重置预加载标志
    hasTriggeredPreload = false
    preloadedNextEpisodeUrl = null
    releaseBackgroundPlayer()  // 释放后台播放器
    
    // 自动播放下一集
    if (isShortDrama && shortDramaManager.hasNextEpisode()) {
        shortDramaManager.onPlaybackEnded { episode ->
            playShortDramaEpisode(episode)
        }
    }
}
```

## 性能优化

### 1. 后台线程处理
- URL获取在 IO 线程执行
- 避免阻塞主线程

### 2. 资源管理
- 及时释放后台播放器
- 避免内存泄漏

### 3. 错误处理
- 预加载失败不影响正常播放
- 自动降级到常规加载方式

## 预期效果

1. **播放流畅度提升**
   - 下一集切换时间从 3-5秒 降低到 < 1秒
   - 用户感知到的是"无缝切换"

2. **用户体验改善**
   - 不再有明显的加载等待
   - 倒计时提示让用户有控制感

3. **网络优化**
   - 提前利用播放间隙加载内容
   - 减少用户等待时间

## 注意事项

1. **内存使用**
   - 后台播放器会占用额外内存
   - 建议在低内存设备上监控

2. **网络流量**
   - 预加载会消耗额外流量
   - 可以考虑添加"仅WiFi预加载"选项

3. **电池消耗**
   - 后台缓冲会增加电池消耗
   - 可以考虑添加省电模式

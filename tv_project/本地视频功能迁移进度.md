## 使用说明

### 访问本地视频
1. 打开应用
2. 进入"设置"页面
3. 点击"本地视频"图标（现在使用 `offline.png`）
4. 授予存储权限
5. 选择视频文件夹
6. 选择视频播放

### 播放器手势
- **单击**：显示/隐藏控制栏
- **双击**：播放/暂停
- **长按**：2倍速快进
- **左右滑动**：调整播放进度
- **左侧上下滑动**：调整屏幕亮度
- **右侧上下滑动**：调整音量

### 播放器功能
- **锁定按钮**：锁定屏幕，防止误触
- **截屏按钮**：截取当前画面
- **分享按钮**：分享视频链接
- **投屏按钮**：复制视频地址用于投屏
- **菜单按钮**：更多选项（画面比例、系统播放器等）
- **倍速按钮**：循环切换播放速度
- **选集按钮**：选择播放集数
- **下一集按钮**：播放下一集

## 技术说明

### 缩略图加载
当前使用的 `MediaStore.Video.Thumbnails.getThumbnail()` 方法在 API 29 (Android 10) 已弃用。
建议后续升级为使用 `ThumbnailUtils.createVideoThumbnail()` 或 `ContentResolver.loadThumbnail()`。

### 视频扫描
使用 `MediaStore` API 扫描本地视频，支持：
- 按文件夹分组
- 异步加载缩略图
- 占位图显示

### 播放器
使用 ExoPlayer 作为播放引擎，支持：
- 多种视频格式
- 流媒体播放
- 本地文件播放
- DRM 内容播放

# 📋 快速参考 - 图片加载优化

## 🎯 一句话总结
通过**多线程并发**（6线程）+ **智能预加载**（前20张）+ **优先级管理**，实现**3-6倍**加载速度提升。

---

## ⚡ 核心功能

| 功能 | 说明 | 效果 |
|------|------|------|
| 多线程并发 | 6个网络线程同时加载 | 速度提升3-6倍 |
| 智能预加载 | 自动预加载前20张图片 | 滚动无等待 |
| 优先级管理 | 轮播图和首屏优先 | 关键内容先显示 |
| 智能缓存 | 原图+转换图双缓存 | 二次加载秒开 |
| 性能监控 | 实时统计分析 | 问题快速定位 |

---

## 📝 常用代码

### 基本加载
```kotlin
ImageLoader.load(context, url, imageView, placeholder)
```

### 高优先级加载
```kotlin
ImageLoader.load(context, url, imageView, placeholder, Priority.HIGH)
```

### 轮播图加载
```kotlin
ImageLoader.loadBanner(context, url, imageView, placeholder)
```

### 批量预加载
```kotlin
val urls = videos.take(20).mapNotNull { it.coverUrl }
ImageLoader.preloadImages(context, urls)
```

### 查看统计
```kotlin
ImageLoadMonitor.printReport()
```

## 💡 最佳实践

1. **使用ImageLoader替代Glide**
   ```kotlin
   // ❌ 不推荐
   Glide.with(context).load(url).into(imageView)
   
   // ✅ 推荐
   ImageLoader.load(context, url, imageView, placeholder)
   ```

2. **重要内容使用高优先级**
   ```kotlin
   ImageLoader.load(context, url, imageView, placeholder, Priority.HIGH)
   ```

3. **列表页面添加预加载**
   ```kotlin
   val urls = items.take(20).mapNotNull { it.imageUrl }
   ImageLoader.preloadImages(context, urls)
   ```

4. **定期查看性能统计**
   ```kotlin
   ImageLoadMonitor.printReport()
   ```

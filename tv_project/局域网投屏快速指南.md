# 局域网投屏到电脑 - 快速使用指南

## 🎯 功能简介

在播放视频时，可以将视频投屏到局域网内的电脑浏览器播放，支持 M3U8 和 MP4 格式，自动添加请求头。

## 📱 使用步骤

### 1️⃣ 打开投屏菜单
在视频播放界面，点击右上角的 **投屏** 按钮

### 2️⃣ 查看扫描结果
投屏菜单会显示两个区域：
- **DLNA 设备**：传统的 DLNA 投屏设备（电视、盒子等）
- **局域网电脑**：自动扫描到的电脑设备

### 3️⃣ 选择电脑设备
在"局域网电脑"区域，点击要投屏的电脑

### 4️⃣ 在电脑浏览器打开
- 会弹出对话框，显示播放地址（例如：`http://192.168.1.100:8888`）
- 点击 **复制地址** 按钮
- 在电脑的浏览器中粘贴并打开该地址
- 视频会自动开始播放 🎬

## ✨ 功能特点

### M3U8 视频
- 使用专业的 DPlayer 播放器
- 自动添加 Referer 和 User-Agent 请求头
- 支持在线播放，无需下载
- 支持快进/快退/音量调节/截图

### MP4 视频
- 使用浏览器原生播放器
- 直接播放，速度快
- 支持全屏播放
- 兼容所有现代浏览器

## 🔧 技术细节

### 自动扫描
- 扫描整个局域网段（192.168.x.x）
- 通过主机名识别电脑设备
- 检测常见 HTTP 端口（80, 8080, 3000, 5000）
- 实时显示发现的设备数量

### 本地服务器
- 自动启动 HTTP 服务器（端口 8888）
- 生成专业的播放页面
- 自动处理请求头转发
- 支持多种视频格式

## ⚠️ 注意事项

### 网络要求
- 手机和电脑必须在 **同一个 WiFi 网络**
- 手机需要连接 WiFi（不支持移动数据）
- 路由器不能启用 AP 隔离功能

### 使用限制
- 播放期间不要退出应用
- 不要切换网络
- 确保手机不会自动休眠

### 防火墙
- 某些电脑防火墙可能阻止访问
- 如果无法访问，请临时关闭防火墙测试

## 🐛 常见问题

### Q: 扫描不到电脑？
**解决方法：**
1. 确认手机和电脑在同一 WiFi
2. 点击刷新按钮重新扫描
3. 检查路由器是否启用了 AP 隔离
4. 尝试在电脑上 ping 手机 IP

### Q: 复制地址后打不开？
**解决方法：**
1. 确保应用没有退出或切换到后台
2. 检查地址格式（应该是 http://192.168.x.x:8888）
3. 尝试在电脑浏览器中直接输入地址
4. 检查电脑防火墙设置

### Q: 视频播放卡顿？
**解决方法：**
1. 靠近路由器，增强信号
2. 关闭其他占用网络的应用
3. 使用 5GHz WiFi（如果支持）
4. 降低视频清晰度

### Q: M3U8 播放失败？
**解决方法：**
1. 某些视频源有防盗链保护
2. 尝试使用"复制视频地址"功能
3. 查看浏览器控制台的错误信息
4. 尝试其他视频源

## 💡 使用技巧

### 技巧 1：快速重连
如果之前投屏过，地址不会变，可以在浏览器中添加书签，下次直接打开

### 技巧 2：多设备观看
可以同时在多台电脑上打开同一个地址，实现多设备同时观看

### 技巧 3：大屏观看
适合在电脑大屏幕上观看视频，体验更好

### 技巧 4：保持连接
播放期间保持手机屏幕常亮，避免应用被系统休眠

# 📺 局域网投屏功能使用说明

## 🎯 功能概述

支持将手机上的视频投屏到电脑浏览器播放，支持 M3U8 和 MP4 格式。

### ✨ 核心功能

- ✅ **选集播放**：支持多集视频切换
- ✅ **自动下一集**：播放完自动播放下一集（3秒倒计时）
- ✅ **智能降级**：直接访问 → 远程代理 → 本地代理
- ✅ **详细日志**：浏览器控制台和服务器端完整日志
- ✅ **调试页面**：`/debug` 路径查看服务器状态

---

## 🚀 快速开始

### 1️⃣ 启动投屏

1. 在 APP 中播放视频
2. 点击**投屏按钮**
3. 选择**"电脑浏览器"**或选择电脑设备
4. 等待提示：**"✅ 服务器已就绪"**（约1秒）
5. 选择复制方式：
   - **复制地址**：本地服务器（需要手机运行）
   - **远程链接**：远程服务器（无需手机，可分享）✨ 新增

### 2️⃣ 电脑端访问

**本地模式：**
1. 在电脑浏览器中粘贴地址（如：`http://192.168.31.166:8888`）
2. 手机需保持运行
3. 仅限同一WiFi

**远程模式：**✨ 新增
1. 在任何设备浏览器中粘贴地址（如：`https://2trip.xyz/spsp/index.html?url=...`）
2. 手机可以关闭
3. 可以分享给朋友

### 3️⃣ 选集操作

- 点击右下角 **📋 选集 (1/24)** 按钮
- 弹出选集面板，点击任意集数切换
- 播放完自动播放下一集（3秒倒计时）

## 🔧 代理模式说明

### 三种播放模式

播放器会按以下顺序自动尝试：

#### 1. 直接访问（优先）
```
浏览器 → 视频源
```
- **优点**：速度最快，无中间环节
- **适用**：视频源无防盗链限制
- **失败原因**：CORS 限制、防盗链

#### 2. 远程代理（降级1）
```
浏览器 → 远程PHP代理 → 视频源
```
- **优点**：手机可以关闭，流量走代理服务器
- **配置**：`LocalWebServer.REMOTE_PROXY_URL`
- **失败原因**：代理服务器不稳定、超时

#### 3. 本地代理（降级2）
```
浏览器 → 手机本地服务器 → 视频源
```
- **优点**：最稳定，完全控制
- **缺点**：手机需保持运行
- **端口**：8888

### 远程代理配置

在 `LocalWebServer.kt` 中配置：

```kotlin
companion object {
    // 远程代理地址（留空则不使用）
    var REMOTE_PROXY_URL = "https://2trip.xyz/spsp/video-proxy.php"
}
```

**远程代理服务器部署：**
- 只需部署一个文件：`video-proxy.php`
- 支持 m3u8 路径重写
- 自动添加 Referer 和 User-Agent
- 支持重试机制（最多3次）

## 🌐 远程播放器部署

### 服务器文件

```
/spsp/
├── video-proxy.php      # 代理脚本

### 部署步骤

1. 将 `spsp-index.html` 重命名为 `index.html`
2. 上传到服务器（与 `video-proxy.php` 同目录）
3. 确保可以访问：`https://2trip.xyz/spsp/index.html`

### 使用方法

**方式1：APP 自动生成（推荐）**
- 点击投屏对话框的"远程链接"按钮
- 自动生成并复制链接
- 在任何设备浏览器中打开

**方式2：手动构建链接**

单个视频：
```
https://2trip.xyz/spsp/index.html?url=视频地址&title=标题
```

多集视频：
```
https://2trip.xyz/spsp/index.html?url=第1集地址&title=剧名&episodes=[{"title":"第1集","url":"地址1"}]&index=0
```

## 🔒 安全说明

### 网络要求

- 手机和电脑必须在**同一WiFi**
- 服务器监听 `0.0.0.0:8888`（局域网可访问）

### 数据流向

**本地代理模式：**
```
电脑浏览器 → 手机(8888端口) → 视频源
```

**远程代理模式：**
```
电脑浏览器 → 远程PHP代理 → 视频源

### 注意事项

- ⚠️ 本地代理模式下，手机需保持运行
- ⚠️ 远程代理模式下，流量走代理服务器
- ⚠️ 不要在公共WiFi下使用（安全风险）

## 🆘 常见问题

### Q1: 打开网址后页面空白？

**A:** 
1. 访问 `http://192.168.31.166:8888/debug` 查看服务器状态
2. 检查视频URL是否为空
3. 按F12查看浏览器控制台错误

### Q2: 视频无法播放？

**A:**
1. 查看浏览器控制台日志
2. 检查是否有 CORS 错误（会自动降级到代理）
3. 检查网络连接
4. 尝试刷新页面

### Q3: 选集按钮不显示？

**A:**
- 确认调用了 `setVideoInfoWithEpisodes()` 方法
- 确认 `episodes` 列表不为空
- 访问 `/debug` 查看剧集数量

### Q4: 自动下一集不工作？

**A:**
- 确认剧集列表已正确传入
- 查看浏览器控制台是否有错误
- 确认不是最后一集

### Q5: 远程代理返回500错误？

**A:**
1. 检查 PHP 服务器日志
2. 确认 cURL 扩展已安装
3. 检查视频源是否可访问
4. 会自动降级到本地代理

### Q6: 手机和电脑不在同一WiFi？

**A:**
- 必须在同一局域网
- 检查手机和电脑的IP段是否一致
- 尝试关闭防火墙

# 可可影视详情页解析修复 - 更新日志

## 版本信息
- **修复日期**: 2026-04-15
- **问题**: 可可影视详情页无法解析标题、简介等信息
- **状态**: ✅ 已完成

## 问题描述

用户反馈可可影视的剧集详情页面无法正确解析以下信息：
- 视频标题
- 视频简介
- 年份、地区、类型
- 导演、主演

## 根本原因

可可影视的HTML结构与其他视频源不同，原有的解析器使用的正则表达式模式无法匹配可可影视的特定HTML结构。

## 解决方案

### 1. 增强标题解析
添加多种标题解析模式，按优先级尝试：

```kotlin
val titlePatterns = listOf(
    """<h1[^>]*class="[^"]*detail-title[^"]*"[^>]*>([^<]+)</h1>""".toRegex(),
    """<div[^>]*class="[^"]*detail-title[^"]*"[^>]*>([^<]+)</div>""".toRegex(),
    """<h2[^>]*class="[^"]*title[^"]*"[^>]*>([^<]+)</h2>""".toRegex(),
    """<h1[^>]*>([^<]+)</h1>""".toRegex(),
    """<title>([^<-]+)""".toRegex() // 从页面标题提取
)
```

**特点**：
- 支持多种HTML标签（h1, h2, div）
- 支持不同的class名称
- 最后兜底从页面title标签提取

### 2. 增强封面解析
添加多种封面图片解析模式：

```kotlin
val coverPatterns = listOf(
    """<img[^>]*class="[^"]*lazy[^"]*"[^>]*data-original="([^"]+)"""".toRegex(),
    """<img[^>]*data-original="([^"]+)"[^>]*class="[^"]*lazy[^"]*"""".toRegex(),
    """<img[^>]*class="[^"]*lazyload[^"]*"[^>]*data-original="([^"]+)"""".toRegex(),
    """<div[^>]*class="[^"]*detail-pic[^"]*"[^>]*>.*?<img[^>]*src="([^"]+)"""".toRegex(RegexOption.DOT_MATCHES_ALL)
)
```

**特点**：
- 支持lazy和lazyload类
- 支持data-original和src属性
- 支持不同的属性顺序

### 3. 增强简介解析
添加多种简介解析模式，并自动清理前缀：

```kotlin
val descPatterns = listOf(
    """<div[^>]*class="[^"]*detail-desc[^"]*"[^>]*>([^<]+)</div>""".toRegex(),
    """<div[^>]*class="[^"]*desc[^"]*"[^>]*>([^<]+)</div>""".toRegex(),
    """<p[^>]*class="[^"]*detail-content[^"]*"[^>]*>([^<]+)</p>""".toRegex(),
    """<span[^>]*class="[^"]*detail-content[^"]*"[^>]*>([^<]+)</span>""".toRegex(),
    """<meta[^>]*name="description"[^>]*content="([^"]+)"""".toRegex() // 从meta标签提取
)

// 自动清理前缀（如"柔美的细胞小将第三季："）
if (description.contains("：")) {
    val parts = description.split("：", limit = 2)
    if (parts.size == 2) {
        description = parts[1].trim()
    }
}
```

**特点**：
- 支持多种HTML标签（div, p, span）
- 支持从meta标签提取
- 自动清理标题前缀

### 4. 增强元数据解析
为年份、地区、类型、导演、主演添加多种解析模式：

```kotlin
val infoPatterns = mapOf(
    "year" to listOf(
        """年份[：:]\s*<[^>]*>([^<]+)<""".toRegex(),
        """年份[：:]\s*([^<\n]+)""".toRegex(),
        """<span[^>]*>年份[：:]</span>\s*<[^>]*>([^<]+)<""".toRegex()
    ),
    // ... 其他字段类似
)
```

**特点**：
- 支持带HTML标签的格式
- 支持纯文本格式
- 支持span标签包裹的标签名

## 解析策略

### 优先级顺序
1. **最具体的模式**：包含完整class名称的模式
2. **通用模式**：只匹配标签类型的模式
3. **兜底模式**：从meta标签或title标签提取

## 已知限制

1. **HTML结构变化**：如果可可影视更新HTML结构，可能需要添加新的解析模式
2. **动态内容**：如果内容通过JavaScript动态加载，当前解析器无法获取
3. **特殊字符**：某些特殊字符可能需要额外处理

## 后续优化建议

1. **使用HTML解析库**：考虑使用Jsoup等专业HTML解析库，替代正则表达式
2. **缓存解析结果**：避免重复解析相同的详情页
3. **异步解析**：对于大型HTML，考虑异步解析以提高性能
4. **自动化测试**：添加单元测试，验证各种HTML结构的解析

# 可可影视修复总结

## 问题

1. **列表页无法加载视频** - 解析逻辑不匹配实际HTML结构
2. **图片不显示** - 图片URL处理问题
3. **剧集页未适配** - 剧集列表解析逻辑不正确

## 修复内容

### 1. 列表页解析修复 (`HomeViewModel.kt`)

**问题分析**：
- 实际HTML中有**多个** `<img>` 标签（第一个是占位符，第二个是真实封面）
- 实际HTML中有**多个** `v-item-title`（隐藏的占位符和真实标题）

**HTML结构**：
```html
<a href="/detail/333078.html" class="v-item">
  <div class="v-item-main">
    <div class="v-item-cover">
      <img data-original="placeholder.png">  <!-- 占位符 -->
      <img data-original="/vod1/vod/cover/xxx.webp">  <!-- 真实封面 -->
    </div>
  </div>
  <div class="v-item-footer">
    <div class="v-item-title" style="display: none">可可影视</div>  <!-- 隐藏 -->
    <div class="v-item-title">追恶</div>  <!-- 真实标题 -->
    <div class="v-item-title" style="display: none">可可影视</div>  <!-- 隐藏 -->
  </div>
</a>
```

**解决方案**：
- 分步解析：先找到所有 `v-item` 链接块
- 在每个块中查找所有图片，取**第二个**图片（跳过占位符）
- 在每个块中查找所有标题，取**不包含"可可影视"**的标题

**代码位置**：`app/src/main/java/com/tv/ball/presentation/home/HomeViewModel.kt` 第 240-310 行

### 2. 图片URL处理

**问题**：图片URL是相对路径 `/vod1/vod/cover/...`

**解决方案**：
```kotlin
var fullImg = when {
    img.startsWith("//") -> "https:$img"
    img.startsWith("/") -> baseUrl + img  // 添加基础URL
    else -> img
}
```

**基础URL**：`https://103.194.185.51:51120`

### 3. 剧集页解析修复 (`VideoDetailParser.kt`)

**问题分析**：
- 可可影视使用 `episode-list-box` 和 `episode-item` 结构
- 多个播放源，每个源在单独的 `episode-list` div中

**HTML结构**：
```html
<div class="episode-list-box">
  <div class="episode-list" style="">  <!-- 线路1，默认显示 -->
    <a href="/play/333078-32-3516190.html" class="episode-item">
      <span>1080P</span>
    </a>
  </div>
  <div class="episode-list" style="display: none;">  <!-- 线路2，默认隐藏 -->
    <a href="/play/333078-35-3516683.html" class="episode-item">
      <span>1080P</span>
    </a>
  </div>
</div>
```

**解决方案**：
- 查找所有 `<div class="episode-list">` 块
- 在每个块中提取所有 `episode-item` 链接
- 为每个线路添加标识：`[线路1]`, `[线路2]` 等

**代码位置**：`app/src/main/java/com/tv/ball/data/parser/VideoDetailParser.kt` 第 380-450 行

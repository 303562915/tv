# 图片加载优化 - 快速开始

## 核心改进

### ✅ 已完成的优化

1. **多线程并发加载**
   - 6个网络加载线程同时工作
   - 4个磁盘缓存线程
   - 大幅提升加载速度

2. **智能预加载**
   - 首页自动预加载前20张图片
   - 轮播图预加载所有图片
   - 使用低优先级，不影响当前浏览

3. **优先级管理**
   - 轮播图：高优先级
   - 首屏内容：高优先级
   - 其他内容：普通优先级

## 效果对比

### 优化前
- 单线程加载，图片逐个加载
- 滚动时需要等待图片下载
- 轮播图切换可能出现白屏

### 优化后
- 6线程并发，图片快速加载
- 预加载机制，滚动流畅无等待
- 轮播图预加载，切换无延迟

## 如何使用

### 1. 替换现有的Glide调用

**之前:**
```kotlin
Glide.with(context)
    .load(imageUrl)
    .placeholder(R.drawable.placeholder)
    .into(imageView)
```

**现在:**
```kotlin
ImageLoader.load(
    context = context,
    url = imageUrl,
    imageView = imageView,
    placeholder = R.drawable.placeholder
)
```

### 2. 添加预加载（可选）

在数据加载完成后添加预加载：
```kotlin
viewModel.videos.collect { videos ->
    adapter.submitList(videos)
    
    // 预加载图片
    val imageUrls = videos.take(20).mapNotNull { it.coverUrl }
    ImageLoader.preloadImages(context, imageUrls)
}
```

## 配置说明

所有配置都在 `GlideConfiguration.kt` 中，默认配置已优化，通常无需修改。

如需调整线程数：
```kotlin
// 网络加载线程数（默认6）
builder.setSourceExecutor(
    GlideExecutor.newSourceBuilder()
        .setThreadCount(6)  // 可调整为 4-8
        .build()
)
```

## 性能建议

1. **预加载数量**: 建议20-30张，平衡性能和内存
2. **并发线程**: 默认6个已优化，不建议超过8个
3. **优先级**: 首屏内容使用HIGH，其他使用NORMAL

## 监控日志

查看日志了解加载情况：
```
adb logcat | grep -E "ImageLoader|GlideConfiguration"
```

关键日志：
- `Glide多线程配置完成`: 配置已生效
- `开始预加载 X 张图片`: 预加载开始
- `预加载进度: X/Y`: 预加载进度

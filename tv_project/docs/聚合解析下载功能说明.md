# 聚合解析下载功能说明

## 功能概述

为聚合解析功能添加了完整的下载支持，包括视频下载和图片下载功能。

## 新增功能

### 1. 视频下载
- 在解析结果页面，点击"下载"按钮可直接下载视频
- 视频会自动添加到下载管理器中
- 支持断点续传和多线程下载

### 2. 图片下载

#### 2.1 全部下载
- 对于图集内容，点击"下载"按钮会弹出选项
- 选择"下载全部图片"可一次性下载所有图片
- 图片会按顺序命名：`标题_1.jpg`, `标题_2.jpg` 等

#### 2.2 单张下载
- 点击"下载"按钮后选择"选择单张下载"
- 会显示图片列表供选择
- 选择后单独下载该图片

#### 2.3 图片预览
- 点击图集中的任意图片可进入全屏预览模式
- 支持左右滑动查看所有图片
- 预览界面显示当前图片序号（如 1/10）
- 预览界面可直接下载当前查看的图片

### 3. UI 改进
- 添加了"下载"按钮，与"播放"和"复制链接"按钮并列
- 按钮采用 Material Design 风格
- 下载按钮使用下载图标，视觉效果更直观

### 核心功能

#### 1. 下载管理器集成
```kotlin
private val videoDownloader by lazy { VideoDownloader.getInstance(this) }
```

#### 2. 视频下载
```kotlin
private fun downloadVideo(url: String, title: String) {
    val taskId = videoDownloader.addDownloadTask(url, title)
    videoDownloader.startDownload(taskId)
}
```

#### 3. 图片批量下载
```kotlin
private fun downloadAllImages(images: List<String>, title: String) {
    images.forEachIndexed { index, url ->
        val fileName = "${title}_${index + 1}"
        val taskId = videoDownloader.addDownloadTask(url, fileName)
        videoDownloader.startDownload(taskId)
    }
}
```

#### 4. 图片预览
- 使用 `ViewPager2` 实现左右滑动
- 支持手势缩放和拖动
- 全屏沉浸式体验

## 使用流程

### 视频下载流程
1. 在聚合解析页面输入视频链接
2. 点击"开始解析"
3. 解析成功后，点击"下载"按钮
4. 视频自动添加到下载列表

### 图片下载流程

#### 方式一：全部下载
1. 解析图集链接
2. 点击"下载"按钮
3. 选择"下载全部图片"
4. 所有图片自动添加到下载列表

#### 方式二：单张下载（列表选择）
1. 解析图集链接
2. 点击"下载"按钮
3. 选择"选择单张下载"
4. 在列表中选择要下载的图片

#### 方式三：单张下载（预览模式）
1. 解析图集链接
2. 点击任意图片进入预览模式
3. 左右滑动查看不同图片
4. 点击"下载当前图片"按钮下载

## 注意事项

1. 下载的文件保存在应用的下载目录中
2. 需要存储权限才能下载文件
3. 下载进度可在"下载管理"页面查看
4. 支持后台下载，退出应用后继续下载
5. 图片文件名会自动添加序号，避免重名

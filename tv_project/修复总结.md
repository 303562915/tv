# DNS 解析问题修复总结

## 问题

你遇到的错误：
```
Unable to resolve host "play.ly166.com": No address associated with hostname
```

链接：`https://play.ly166.com:65/videos/20251216/694174af80eee9b95522bf39/acafef/index.m3u8`

**现象**：
- ✗ 应用内下载失败
- ✗ 播放器无法播放
- ✓ 手机浏览器可以播放

## 根本原因

这是一个 **DNS 解析失败**的问题：

1. **Android 应用的 DNS 解析**使用 Java 网络库，依赖系统 DNS 设置
2. **浏览器的 DNS 解析**可能使用自己的 DNS 服务器（如 Chrome 的 DoH）
3. 某些域名（如 `play.ly166.com`）可能在某些 DNS 服务器上无法解析

## 解决方案

我为你的应用添加了**自定义 DNS 解析功能**，会自动尝试多个公共 DNS 服务器。

### 新增文件

1. **`CustomDnsResolver.kt`** - 自定义 DNS 解析器
   - 支持 Google DNS、Cloudflare DNS、阿里 DNS 等
   - 使用 DNS over HTTPS (DoH) 技术
   - 自动尝试多个 DNS 服务器

2. **`EnhancedUrlConnection.kt`** - 增强的 URL 连接工具
   - 自动使用自定义 DNS 解析
   - 支持 HTTPS 的 SNI
   - 失败时自动回退

3. **`NetworkDiagnostics.kt`** - 网络诊断工具
   - 诊断 DNS 解析问题
   - 测试网络连接
   - 提供修复建议

4. **`NetworkTestHelper.kt`** - 测试辅助工具
   - 快速测试 URL
   - 生成诊断报告

### 修改的文件

**`VideoDownloader.kt`** - 所有网络请求现在使用增强的连接：
- `downloadM3u8File()` - M3U8 文件下载
- `downloadSegment()` - M3U8 分片下载  
- `downloadNormalVideo()` - 普通视频下载
- `downloadWithSingleThread()` - 单线程下载

## 工作原理

### 下载流程（修改后）

```
1. 用户点击下载
   ↓
2. VideoDownloader 调用 EnhancedUrlConnection.openConnection()
   ↓
3. EnhancedUrlConnection 调用 CustomDnsResolver.resolve()
   ↓
4. CustomDnsResolver 尝试解析域名：
   - 首先尝试系统 DNS
   - 失败则尝试 Google DNS (8.8.8.8)
   - 失败则尝试 Cloudflare DNS (1.1.1.1)
   - 失败则尝试阿里 DNS (223.5.5.5)
   - ... 直到成功或全部失败
   ↓
5. 如果解析成功，使用 IP 地址创建连接
   - 设置 Host 头为原始域名
   - 设置 SNI（HTTPS）
   ↓
6. 下载开始
```

### DNS over HTTPS (DoH)

使用 HTTPS 查询 DNS，避免 DNS 污染和劫持：

```
Google DoH:      https://dns.google/resolve?name=play.ly166.com&type=A
Cloudflare DoH:  https://cloudflare-dns.com/dns-query?name=play.ly166.com&type=A
阿里 DoH:        https://dns.alidns.com/resolve?name=play.ly166.com&type=A
```

## 播放器修复（如果需要）

如果播放器也无法播放，需要在播放前解析域名。

### 示例代码

```kotlin
import com.tv.ball.domain.network.CustomDnsResolver
import java.net.URL

// 在播放前
lifecycleScope.launch {
    val originalUrl = "https://play.ly166.com:65/videos/xxx/index.m3u8"
    val url = URL(originalUrl)
    val hostname = url.host
    
    // 解析 IP
    val resolvedIp = CustomDnsResolver.resolve(hostname)
    
    if (resolvedIp != null) {
        // 替换域名为 IP
        val newUrl = originalUrl.replace(hostname, resolvedIp)
        
        // 使用 newUrl 播放
        // 注意：需要设置 Host 头
        player.setDataSource(newUrl, mapOf("Host" to hostname))
        player.prepare()
        player.start()
    } else {
        // 显示错误
        Toast.makeText(this@Activity, "无法解析域名", Toast.LENGTH_SHORT).show()
    }
}
```

## 其他可能的问题

### 1. 端口问题

URL 使用了非标准端口 `:65`，某些网络可能会阻止。

**解决方案**：无法在应用层面解决，需要用户切换网络。

### 2. HTTPS 证书问题

如果域名使用 HTTPS 但证书无效，可能导致连接失败。

**解决方案**：已在 `EnhancedUrlConnection` 中设置了自定义的 `HostnameVerifier`。

### 3. 防盗链

某些视频服务器会检查 Referer 和 User-Agent。

**解决方案**：已在所有请求中设置了完整的请求头。

## 如果仍然失败

如果修改后仍然无法下载/播放，可能的原因：

1. **域名真的不存在**：该域名可能已失效
2. **网络被限制**：某些网络（如公司/学校）可能屏蔽了该域名
3. **服务器问题**：视频服务器可能暂时不可用
4. **地区限制**：服务器可能限制了某些地区的访问

**建议**：
- 使用 VPN 测试
- 尝试其他视频源
- 联系视频源提供方

## 性能影响

- **首次解析**：可能需要 1-3 秒（尝试多个 DNS 服务器）
- **后续请求**：DNS 结果会被系统缓存，几乎无影响
- **网络流量**：每次 DNS 查询约 1KB，可忽略不计

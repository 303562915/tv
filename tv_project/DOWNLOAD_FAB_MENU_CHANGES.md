# 下载页面浮动按钮菜单功能实现

## 概述
为下载页面添加了可展开的浮动按钮菜单，复刻了IDM+应用的功能。

## 主要改动

### 1. 布局文件 (activity_download.xml)
- 添加了遮罩层 (`fabOverlay`)，点击时关闭菜单
- 添加了三个子浮动按钮：
  - **从文本文件导入** (绿色 #8BC34A)
  - **从剪贴板** (橙色 #FF7043)
  - **添加链接** (蓝色 #5C6BC0)
- 将主FAB按钮ID从 `fabAdd` 改为 `fabMain`
- 重新组织布局结构，将RecyclerView和FAB按钮放在同一个FrameLayout中

### 2. Activity代码 (DownloadActivity.kt)
添加了以下功能：

#### 菜单展开/收起动画
- `openFabMenu()`: 展开菜单，显示遮罩层和子按钮
- `closeFabMenu()`: 收起菜单，隐藏遮罩层和子按钮
- `toggleFabMenu()`: 切换菜单状态
- 主按钮旋转45度动画
- 子按钮淡入淡出动画

#### 三个功能实现
1. **从文本文件导入**
   - 打开文件选择器
   - 读取文本文件内容
   - 解析每行URL并批量添加下载任务

2. **从剪贴板**
   - 读取剪贴板内容
   - 验证是否为有效URL
   - 自动填充到下载对话框

3. **添加链接**
   - 显示下载配置对话框
   - 手动输入URL和配置

#### 其他改进
- 按返回键时先关闭FAB菜单（如果已打开）
- 处理文件导入的ActivityResult

### 3. 图标资源
创建了三个新的vector drawable图标：
- `drawable/file.xml` - 文件图标
- `drawable/clipboard.xml` - 剪贴板图标
- `drawable/link.xml` - 链接图标

### 4. Dialog改进 (DownloadConfigDialog.kt)
- 添加了兼容Activity使用的构造函数
- 添加了 `setUrl()` 和 `setTitle()` 方法，支持预填充数据

## 使用方式

### 用户操作流程
1. 点击右下角紫色的"+"按钮
2. 按钮旋转45度，展开三个选项
3. 选择需要的功能：
   - 点击"从文本文件导入"：选择包含URL列表的文本文件
   - 点击"从剪贴板"：自动读取剪贴板中的URL
   - 点击"添加链接"：手动输入URL
4. 点击遮罩层或返回键关闭菜单

## 技术细节

### 动画效果
- 遮罩层：淡入淡出 (200ms)
- 主按钮：旋转动画 (200ms)
- 子按钮：淡入淡出 + 平移动画 (200ms)

### 颜色方案
- 主按钮：紫色 (#673AB7)
- 从文本文件导入：绿色 (#8BC34A)
- 从剪贴板：橙色 (#FF7043)
- 添加链接：蓝色 (#5C6BC0)
- 遮罩层：半透明黑色 (#80000000)

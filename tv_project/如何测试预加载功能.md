# 如何测试短剧预加载功能

## 快速测试步骤

### 1. 编译并运行应用
```bash
./gradlew assembleDebug
# 或在 Android Studio 中直接运行
```

### 2. 播放短剧
1. 打开应用
2. 进入短剧详情页
3. 点击播放任意一集

### 3. 观察预加载行为

#### 方法1：查看日志（推荐）
在 Android Studio 的 Logcat 中过滤 `VideoPlayer` 标签：

```
# 预加载触发
触发预加载：剩余 10 秒，开始预加载下一集

# URL获取
⏳ [预加载] 开始预加载下一集: 第2集, videoId=xxx
✅ [预加载] URL获取成功: https://... (耗时: 500ms)

# 后台播放器准备
🎬 [后台播放器] 开始准备播放器
⏳ [后台播放器] 正在缓冲: 5秒
✅ [后台播放器] 准备完成，已缓冲: 15秒

# 播放下一集
✅ 使用预加载的URL
```

#### 方法2：观察用户界面
1. **播放到剩余10秒**
   - 注意：此时后台开始预加载（无UI提示）
   
2. **播放到剩余5秒**
   - 屏幕上会显示"5秒后播放下一集"按钮
   - 倒计时：5、4、3、2、1
   
3. **播放结束**
   - 应该**立即**开始播放下一集
   - 几乎无等待时间（< 1秒）

#### 方法3：对比测试
**测试A：有预加载（当前版本）**
- 播放到结束 → 立即播放下一集（< 1秒）

**测试B：无预加载（禁用功能）**
- 播放到结束 → 显示"正在获取播放地址..." → 等待3-5秒 → 开始播放

## 详细测试场景

5. 观察是否立即播放第2集

**预期结果：**
- ✅ 剩余10秒时触发预加载
- ✅ 剩余5秒时显示倒计时提示

### 场景2：点击立即播放
**步骤：**
1. 播放第1集
2. 快进到剩余8秒
3. 等待倒计时提示出现（剩余5秒）

- ✅ 显示"正在获取播放地址..."
- ✅ 成功播放下一集

1. 播放第1集
2. 快进到剩余8秒（触发预加载）

2. 自动播放第2集到结束
3. 自动播放第3集到结束

**预期结果：**
- ✅ 每次切换都很流畅（< 1秒）
- ✅ 每集都会触发预加载
- ✅ 资源正确释放和重建

## 性能监控

### 内存使用
使用 Android Studio 的 Profiler 监控：
1. 打开 Profiler
2. 选择 Memory
3. 播放短剧并观察内存变化
4. 注意后台播放器创建时的内存增长（约20-50MB）

### 网络流量
1. 打开 Profiler
2. 选择 Network
3. 播放短剧并观察网络请求
4. 注意预加载时的额外流量

### 日志过滤
在 Logcat 中使用以下过滤器：

```
# 只看预加载相关
tag:VideoPlayer 预加载

# 只看后台播放器
tag:VideoPlayer 后台播放器

# 看所有关键日志
tag:VideoPlayer (预加载|后台播放器|使用预加载)
```

## 常见问题

### Q1: 没有看到预加载日志
**可能原因：**
- 视频时长太短（< 10秒）
- 不是短剧模式（IS_SHORT_DRAMA = false）
- 没有下一集

**解决方法：**
- 确保播放的是短剧
- 确保不是最后一集
- 检查 `IS_SHORT_DRAMA` 参数

### Q2: 预加载失败
**可能原因：**
- 网络问题
- API返回错误
- videoId 为空

**解决方法：**
- 检查网络连接
- 查看完整错误日志
- 确认短剧数据完整

### Q3: 切换还是很慢
**可能原因：**
- 预加载未成功
- 后台播放器未准备好
- 网络速度太慢

**解决方法：**
- 检查预加载日志
- 确认后台播放器状态
- 测试网络速度

### Q4: 内存占用过高
**可能原因：**
- 后台播放器未释放
- 缓冲设置过大

**解决方法：**
- 检查释放日志
- 调整缓冲参数
- 考虑添加低内存模式

## 调试技巧

### 1. 修改预加载时机
在 `VideoPlayerActivity.kt` 中修改：
```kotlin
private val preloadThresholdSeconds = 10  // 改为 20 或 30 测试
```

### 2. 强制使用预加载
在 `playShortDramaEpisode()` 中添加日志：
```kotlin
if (preloadedNextEpisodeUrl != null) {
    android.util.Log.d("VideoPlayer", "✅✅✅ 成功使用预加载URL ✅✅✅")
}
```

### 3. 模拟慢网络
在开发者选项中：
- 设置 → 开发者选项 → 网络限速
- 选择 "慢速 3G"

### 4. 查看完整日志
```bash
adb logcat -s VideoPlayer:D ShortDramaManager:D
```

## 测试步骤

### 步骤1: 编译和安装
```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### 步骤2: 启用日志监控
```bash
adb logcat | grep -E "(HomeViewModel|WebDetailParser|VideoSourceManager|可可)"
```

### 步骤3: 测试列表页
1. 打开应用
2. 点击底部"视频源"标签
3. 选择"可可w"源
4. 查看是否能正常加载视频列表
5. 检查日志输出：
   - 应该看到 "可可影视解析到 X 个视频"
   - 如果为0，说明HTML结构不匹配

### 步骤4: 测试详情页
1. 点击任意视频进入详情页
2. 查看是否能正常显示：
   - 标题
   - 封面
   - 简介
   - 剧集列表
3. 检查日志输出：
   - "开始解析可可影视剧集"
   - "可可影视共解析到 X 个剧集"

### 步骤5: 测试播放
1. 点击任意剧集
2. 查看是否能正常播放
3. 如果不能播放，检查视频URL是否正确

### 步骤6: 测试搜索
1. 在搜索页面输入关键词
2. 勾选"可可w"源
3. 点击搜索

## 可能遇到的问题和解决方案

### 问题1: 无法访问域名
**症状**: 网络请求失败，超时
**解决方案**:
1. 检查域名是否可访问：`ping www.keke1.app`
2. 如果域名不可用，可以尝试其他域名或回退到IP
3. 在 `VideoSourceConfig.kt` 中修改URL

### 问题2: SSL证书错误
**症状**: SSL handshake failed
**解决方案**:
需要在 `NetworkDataSource` 中添加SSL证书信任配置（仅用于测试）

### 问题3: 解析不到视频
**症状**: 日志显示"解析到 0 个视频"
**解决方案**:
1. 使用浏览器访问实际URL，查看HTML结构
2. 复制HTML源码
3. 对比代码中的正则表达式
4. 调整正则表达式以匹配实际结构

### 问题4: 剧集列表为空
**症状**: 详情页显示但没有剧集
**解决方案**:
1. 检查 `parseKekeEpisodes` 方法的日志
2. 查看实际的HTML结构
3. 可能需要调整剧集解析的正则表达式

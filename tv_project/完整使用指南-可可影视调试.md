# 完整使用指南 - 可可影视调试

## 🎯 目标

解决"只显示一个视频"的问题，通过查看实际HTML结构来优化解析逻辑。

## 📱 第一步：安装APK

APK位置：`app/build/outputs/apk/debug/app-arm64-v8a-debug.apk`

安装命令：
```bash
adb install -r app/build/outputs/apk/debug/app-arm64-v8a-debug.apk
```

## 🔍 第二步：使用HTML调试工具

### 方法1：通过adb启动

```bash
adb shell am start -n com.tv.ball/.presentation.debug.HtmlDebugActivity
```

### 方法2：在应用中添加入口（临时）

在任意Activity中添加按钮：

```kotlin
// 例如在MainActivity中
findViewById<Button>(R.id.btnDebug).setOnClickListener {
    val intent = Intent(this, HtmlDebugActivity::class.java)
    startActivity(intent)
}
```

### 方法3：通过设置页面

在设置页面添加"HTML调试"选项。

## 📊 第三步：获取HTML结构

1. **打开HTML调试工具**
2. **默认URL已填入**：`https://103.194.185.51:51120/show/1--------1---.html`
3. **点击"获取HTML"按钮**
4. **等待加载完成**

## 🐛 常见问题

### Q: 工具打不开？
A: 使用adb命令启动：
```bash

```

A: 可能是网络问题或SSL证书问题，尝试：

2. 尝试其他URL

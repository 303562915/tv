# 可可影视适配问题分析

## 当前配置

### 1. 基础URL配置
```kotlin
VideoSourceConfig("keke", "可可", SourceType.WEB, "https://103.194.185.51:51120/channel/{category}.html")
```

**问题**：
- 使用IP地址而非域名，可能存在SSL证书问题
- IP地址可能会变化，不稳定
- 注释中提到的域名是 `www.keke1.app`，但实际配置使用的是IP

### 2. 分类映射
```kotlin
"keke" to mapOf(
    1 to "1",    // 电影 -> /channel/1.html
    2 to "2",    // 剧集 -> /channel/2.html
    3 to "3",    // 综艺 -> /channel/3.html
    4 to "4",    // 动漫 -> /channel/4.html
)
```

**问题**：
- 不支持分页（代码中明确注释"不支持分页"）
- 只能显示频道首页的固定内容

### 3. HTML解析规则

#### 列表页解析（HomeViewModel.kt）
```kotlin
val pattern = """<div class="v-item"[^>]*>.*?<a[^>]*href="([^"]+)"[^>]*>.*?<img[^>]*data-original="([^"]+)"[^>]*>.*?<div class="v-item-title"[^>]*>([^<]+)</div>.*?<div class="v-item-note"[^>]*>([^<]*)</div>""".toRegex(RegexOption.DOT_MATCHES_ALL)
```

#### 详情页解析（VideoDetailParser.kt）
- 标题：`<h2 class="title">xxx</h2>`
- 简介：`<div class="desc">xxx</div>`
- 剧集：`<div class="play-list" data-id="1">...</div>`

**问题**：
- HTML结构可能已经变化
- 需要实际测试验证解析规则是否正确

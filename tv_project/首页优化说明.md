# 首页体验优化说明

## 已实现的功能

### 1. 智能预加载（自动下一页）

**功能描述：**
- 当用户滚动到列表底部附近时，自动预加载下一页数据
- 预加载阈值设置为剩余6项时触发，确保用户无感知加载
- 防止滚动到底部时出现卡顿，提升浏览流畅度

**技术实现：**
- 在 `HomeViewModel` 中添加了 `checkAndPreload()` 方法
- 监控用户滚动位置，智能判断何时触发预加载
- 添加了 `hasMorePages` 标志，避免无效请求
- 使用 `isPreloading` 标志防止重复加载

**用户体验：**
- ✅ 无缝浏览，不会看到"加载中"的等待
- ✅ 减少滚动卡顿，提升流畅度
- ✅ 节省流量，只在需要时加载

### 2. 轮播图展开/收起功能

**功能描述：**
- 轮播图支持展开（180dp）和收起（60dp）两种状态
- 向下滚动时自动收起，节省屏幕空间
- 向上滚动到顶部时自动展开
- 点击轮播图可手动切换展开/收起状态

**视觉效果：**
- 平滑的动画过渡（300ms）
- 收起时隐藏指示器，展开时显示
- 底部中央显示展开/收起图标提示
- 图标会根据状态自动切换（向上/向下箭头）

**用户体验：**
- ✅ 浏览内容时自动收起，增加可视区域
- ✅ 想看轮播图时可以手动展开
- ✅ 半透明提示图标，不影响视觉
- ✅ 流畅的动画效果，体验自然

## 代码改动说明

### HomeViewModel.kt
1. 添加了预加载相关变量：
   - `hasMorePages`: 是否还有更多页面
   - `isPreloading`: 是否正在预加载
   - `PRELOAD_THRESHOLD`: 预加载阈值（6项）

2. 新增 `checkAndPreload()` 方法：
   - 智能判断何时触发预加载
   - 避免重复加载和无效请求

3. 优化 `loadVideos()` 方法：
   - 添加页面状态管理
   - 根据返回数据量判断是否还有更多页面

### HomeFragment.kt
1. 添加轮播图状态变量：
   - `isBannerCollapsed`: 轮播图是否收起
   - `BANNER_EXPANDED_HEIGHT`: 展开高度（180dp）
   - `BANNER_COLLAPSED_HEIGHT`: 收起高度（60dp）

2. 新增方法：
   - `setupBannerToggle()`: 设置轮播图点击切换
   - `collapseBanner()`: 收起轮播图
   - `expandBanner()`: 展开轮播图

3. 优化滚动监听：
   - 集成智能预加载
   - 添加自动展开/收起逻辑

### 布局文件 (fragment_home.xml)
1. 轮播图容器添加：
   - 点击效果 (`foreground`)
   - 展开/收起提示图标
   - 半透明圆形背景

### 新增资源文件
1. `ic_expand_more.xml`: 向下箭头图标
2. `ic_expand_less.xml`: 向上箭头图标
3. `circle_background.xml`: 圆形半透明背景

## 使用建议

### 调整预加载阈值
如果需要更早或更晚触发预加载，可以修改 `HomeViewModel.kt` 中的：
```kotlin
private val PRELOAD_THRESHOLD = 6  // 改为其他值，如 9 或 12
```

### 调整轮播图高度
如果需要调整展开/收起的高度，可以修改 `HomeFragment.kt` 中的：
```kotlin
private val BANNER_EXPANDED_HEIGHT = 180 // dp
private val BANNER_COLLAPSED_HEIGHT = 60 // dp
```

### 禁用自动收起
如果不想要自动收起功能，只保留手动切换，可以删除 `setupRecyclerView()` 中的：
```kotlin
// 向下滚动时自动收起轮播图，向上滚动时展开
if (dy > 20 && !isBannerCollapsed) {
    collapseBanner()
} else if (dy < -20 && isBannerCollapsed && layoutManager.findFirstVisibleItemPosition() == 0) {
    expandBanner()
}
```

## 测试建议

1. **预加载测试：**
   - 快速滚动列表，观察是否流畅无卡顿
   - 检查日志中的 "Preloading next page" 信息
   - 确认不会重复加载同一页

2. **轮播图测试：**
   - 向下滚动，观察轮播图是否自动收起
   - 向上滚动到顶部，观察是否自动展开
   - 点击轮播图，测试手动切换功能
   - 检查动画是否流畅

3. **边界情况：**
   - 测试没有更多数据时的表现
   - 测试网络慢时的加载体验
   - 测试快速切换分类时的行为

# 问题分析：投屏能看但播放器看不了

## 问题现象
- 投屏到其他设备可以正常播放
- 应用内播放器无法播放，一直显示加载中
- 没有明显的错误提示

## 根本原因

通过 ADB 日志分析，发现了问题的根本原因：

### 1. 网络连接缓慢
```
视频URL: https://play.ly166.com:65/videos/20260408/69d5d0ed80eee9b9555fa052/9c9g13/index.m3u8
```

测试结果：
- URL 可以访问（返回 200 OK）
- 但是连接速度很慢（2秒才建立连接）
- 使用了非标准端口 65

### 2. 播放器卡在缓冲状态
日志显示：
```
ExoPlayerManager: 播放状态变化: BUFFERING
ExoPlayerManager: 正在缓冲 - 当前位置: 0ms, 缓冲位置: 0ms
ExoPlayerManager: 媒体准备完成
```

播放器状态：
- 成功创建媒体源
- 进入 BUFFERING 状态
- **但一直没有变成 READY 状态**
- 缓冲位置始终为 0ms

### 3. 为什么投屏能看？

投屏设备（如电视、投影仪）可能：
1. **使用不同的网络路径**：可能通过路由器直接访问，而不是手机的移动网络
2. **有更长的超时时间**：投屏协议（如 DLNA）通常有更宽松的超时设置
3. **有更大的缓冲区**：投屏设备可能有更大的内存缓冲
4. **网络质量更好**：投屏设备可能连接的是更快的 WiFi

## 解决方案

### 方案 1: 增加超时时间和重试机制（推荐）

修改 `OkHttpDataSourceFactory.kt`，增加超时时间：

```kotlin
.connectTimeout(15, TimeUnit.SECONDS)   // 从 8秒 增加到 15秒
.readTimeout(20, TimeUnit.SECONDS)      // 从 10秒 增加到 20秒
.callTimeout(60, TimeUnit.SECONDS)      // 从 30秒 增加到 60秒
```

### 方案 2: 添加缓冲超时检测

在播放器中添加超时检测，如果长时间卡在缓冲状态，自动切换到其他视频源或提示用户。

### 方案 3: 优化缓冲策略

修改 `ExoPlayerManager.kt` 中的缓冲配置：

```kotlin
val loadControl = DefaultLoadControl.Builder()
    .setBufferDurationsMs(
        30000,  // 增加最小缓冲时间到 30秒
        180000, // 增加最大缓冲时间到 3分钟
        1,      // 开始播放的最小缓冲保持 1ms
        1       // seek后重新缓冲保持 1ms
    )
    .build()
```

### 方案 4: 添加网络质量检测

在播放前检测网络速度，如果网络太慢，提示用户：
- 切换到 WiFi
- 降低视频质量
- 使用投屏功能

### 方案 5: 添加用户提示

当检测到长时间缓冲时，显示友好的提示：
```
"视频加载较慢，可能是网络问题
建议：
1. 检查网络连接
2. 切换到 WiFi
3. 尝试投屏播放
4. 选择其他视频源"
```

## 立即可以尝试的方法

### 用户端：
1. **切换到 WiFi**：如果当前使用移动数据，切换到 WiFi 可能会更快
2. **等待更长时间**：有时候只是网络慢，多等待一会儿可能会开始播放
3. **使用投屏**：如果播放器不行，继续使用投屏功能
4. **切换视频源**：尝试选择其他视频源

### 开发端：
1. **增加超时时间**（见方案 1）
2. **添加缓冲进度提示**：让用户知道正在加载，而不是卡住了
3. **添加取消按钮**：让用户可以取消长时间的加载

## 技术细节

### 当前超时配置
```kotlin
// OkHttpDataSourceFactory.kt
.connectTimeout(8, TimeUnit.SECONDS)   // 连接超时 8秒
.readTimeout(10, TimeUnit.SECONDS)     // 读取超时 10秒
.callTimeout(30, TimeUnit.SECONDS)     // 整体超时 30秒
```

### 当前缓冲配置
```kotlin
// ExoPlayerManager.kt
.setBufferDurationsMs(
    15000,  // 最小缓冲 15秒
    120000, // 最大缓冲 120秒
    1,      // 开始播放 1ms
    1       // seek后 1ms
)
```

- 使用非标准端口 65
- 域名: play.ly166.com
- 格式: HLS (m3u8)

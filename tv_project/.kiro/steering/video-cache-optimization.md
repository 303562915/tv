# 视频缓存优化

## 已实现的缓存功能

### 1. ExoPlayer 缓存配置
- 缓存大小：30MB（约30秒视频）
- 缓存位置：`context.cacheDir/exoplayer_cache`
- 缓存策略：LRU（最近最少使用）
- 自动清理：缓存满时自动删除最旧的内容

### 2. 缓冲优化
- 最小缓冲：15秒
- 最大缓冲：60秒（1分钟）
- 开始播放：1秒
- 重新缓冲：5秒

### 3. 缓存工作原理
- 网络视频会自动缓存到本地
- 下次播放相同视频时，直接从缓存读取
- 支持 HLS (.m3u8) 和 Progressive (MP4) 格式
- 本地文件不使用缓存（直接读取更快）

### 4. 缓存管理
```kotlin
// 获取缓存大小
val cacheSize = exoPlayerManager.getCacheSize()

// 清理缓存
exoPlayerManager.clearCache()
```

## 用户体验改进

### 播放流畅度
- ✅ 首次播放：需要缓冲
- ✅ 再次播放：从缓存读取，几乎无缓冲
- ✅ 网络波动：使用已缓存的内容继续播放
- ✅ 快进/快退：缓冲的内容可以快速跳转

### 流量节省
- 重复观看的视频不会重复下载
- 缓存会自动管理，不会无限增长
- 30MB 缓存适中，不占用太多空间

# 缺失功能总结

## 🔴 首页缺失的重要功能

### 1. 快捷入口布局（轮播图下方）
**Lua 版本有，Kotlin 版本没有**

应该在轮播图下方添加 4 个快捷入口：
- 历史收藏 (history_collection.png)
- 本地视频 (vn.png)
- 高清收藏 (ic_pv.png)
- 扩展工具 (ic_lw.png)

位置：在 `bannerContainer` 和 `tabLayout` 之间

### 2. 继续播放卡片
**Lua 版本在首页顶部，Kotlin 版本只在设置页**

应该在轮播图上方或下方显示最近播放的视频，点击可以继续播放。

### 3. 视频列表列数
- Lua 版本：2 列
- Kotlin 版本：3 列
- 建议：改回 2 列，显示更大的封面

## 🟡 其他缺失功能

### 1. 主题色选择
ThemeActivity 只有占位页面，需要实现：
- 颜色选择器
- 保存用户选择
- 应用到全局

### 2. 聚合解析
ParserActivity 只有占位页面，需要实现视频解析功能

### 3. 扩展工具弹窗
点击扩展工具应该显示下载工具弹窗，而不是 Toast

### 4. 投屏功能
播放器缺少 DLNA 投屏功能

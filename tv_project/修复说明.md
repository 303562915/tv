### 4. 播放器横竖屏切换功能 ✅

**问题描述**: 播放器只支持横屏，不支持横竖屏切换

**修复内容**:
- 修改 `app/src/main/java/com/tv/ball/presentation/player/VideoPlayerActivity.kt`
  - 允许横竖屏自动切换：`requestedOrientation = ActivityInfo.SCREEN_ORIENTATION_SENSOR`
  - 添加 `onConfigurationChanged()` 方法监听屏幕方向变化
  - 添加 `updateOrientationUI()` 方法根据屏幕方向调整UI
  - 横屏时：全屏显示，隐藏系统状态栏和导航栏
  - 竖屏时：显示系统UI，正常显示状态栏
  - 更新全屏按钮图标以反映当前状态

**修复代码**:
```kotlin
override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    binding = ActivityVideoPlayerBinding.inflate(layoutInflater)
    setContentView(binding.root)
    
    // 允许横竖屏切换
    requestedOrientation = ActivityInfo.SCREEN_ORIENTATION_SENSOR
    
    // 设置全屏和保持屏幕常亮
    window.addFlags(WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON)
    
    // ... 其他初始化代码
    
    // 初始化时根据当前方向调整布局
    updateOrientationUI()
}

override fun onConfigurationChanged(newConfig: android.content.res.Configuration) {
    super.onConfigurationChanged(newConfig)
    updateOrientationUI()
}

private fun updateOrientationUI() {
    val isLandscape = resources.configuration.orientation == 
        android.content.res.Configuration.ORIENTATION_LANDSCAPE
    
    if (isLandscape) {
        // 横屏：全屏显示，隐藏系统UI
        window.decorView.systemUiVisibility = (
            View.SYSTEM_UI_FLAG_FULLSCREEN or
            View.SYSTEM_UI_FLAG_HIDE_NAVIGATION or
            View.SYSTEM_UI_FLAG_IMMERSIVE_STICKY
        )
        binding.fullscreenButton.setImageResource(android.R.drawable.ic_menu_close_clear_cancel)
    } else {
        // 竖屏：显示系统UI
        window.decorView.systemUiVisibility = View.SYSTEM_UI_FLAG_VISIBLE
        binding.fullscreenButton.setImageResource(android.R.drawable.ic_menu_crop)
    }
}

private fun toggleOrientation() {
    requestedOrientation = if (resources.configuration.orientation == 
        android.content.res.Configuration.ORIENTATION_LANDSCAPE) {
        ActivityInfo.SCREEN_ORIENTATION_SENSOR_PORTRAIT
    } else {
        ActivityInfo.SCREEN_ORIENTATION_SENSOR_LANDSCAPE
    }
}
```

**功能说明**:
- 用户可以通过点击全屏按钮切换横竖屏
- 也可以通过旋转设备自动切换横竖屏
- 横屏时视频全屏显示，提供沉浸式观看体验
- 竖屏时视频按比例显示，下方可以显示更多信息（未来可扩展）

**未来扩展**:

- 竖屏时可以显示选集列表
- 竖屏时可以显示视频详情和评论

## 数据流程说明

### 历史记录保存流程
1. 用户在 VideoDetailActivity 点击播放视频
2. VideoDetailActivity 传递封面 URL 给 VideoPlayerActivity
3. VideoPlayerActivity 将封面 URL 传递给 VideoPlayerViewModel
4. VideoPlayerViewModel 在 `savePlaybackProgress()` 中保存历史记录到数据库
5. HistoryEntity 包含 thumbnailUrl 字段

### 历史记录显示流程
1. HistoryFragment 加载历史记录
2. HistoryViewModel 从数据库读取 HistoryEntity
3. 将 HistoryEntity 转换为 VideoItem，包括 coverUrl
4. VideoListAdapter 使用 Glide 加载封面图片

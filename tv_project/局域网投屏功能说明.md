# 局域网投屏到电脑功能说明

## 功能概述

新增了局域网投屏到电脑的功能，可以让局域网内的电脑浏览器直接播放视频，支持 M3U8 和 MP4 等格式，自动添加请求头。

## 功能特点

### 1. 自动扫描局域网设备
- 自动扫描局域网内的电脑设备（192.168.x.x 网段）
- 识别电脑设备（通过主机名和 HTTP 端口检测）
- 实时显示发现的设备数量

### 2. 一键投屏到电脑
- 点击扫描到的电脑设备
- 自动启动本地 HTTP 服务器（端口 8888）
- 生成播放页面 URL
- 显示对话框，提供复制地址功能

### 3. 智能播放页面
- **M3U8 视频**：使用 DPlayer + hls.js 播放器
  - 自动添加 Referer 和 User-Agent 请求头
  - 支持在线播放，无需下载
  - 支持快进/快退/音量调节
  
- **MP4 视频**：使用 HTML5 原生播放器
  - 直接播放，速度快
  - 支持所有浏览器
  - 支持全屏播放

### 4. 用户友好的界面
- 分为两个区域：DLNA 设备 和 局域网电脑
- 显示设备名称和 IP 地址
- 显示扫描状态和设备数量
- 提供刷新按钮重新扫描

## 使用方法

### 步骤 1：打开投屏菜单
在视频播放页面，点击"投屏"按钮

### 步骤 2：等待扫描完成
- 应用会自动扫描局域网内的设备
- DLNA 设备显示在上方
- 电脑设备显示在"局域网电脑"区域

### 步骤 3：选择电脑设备
点击要投屏的电脑设备

### 步骤 4：在电脑浏览器打开
- 会弹出对话框显示播放地址
- 点击"复制地址"
- 在电脑浏览器中粘贴并打开该地址
- 视频会自动开始播放

## 网络要求

- 手机和电脑必须在同一个 WiFi 网络
- 手机需要有 WiFi 连接（不支持移动数据）
- 电脑需要能访问局域网内的其他设备
- 防火墙不能阻止 8888 端口

## 常见问题

### Q: 扫描不到电脑设备？
A: 
1. 确保手机和电脑在同一个 WiFi 网络
2. 检查电脑防火墙设置
3. 点击刷新按钮重新扫描
4. 某些路由器可能启用了 AP 隔离，需要关闭

### Q: 复制地址后电脑浏览器打不开？
A: 
1. 确保手机应用没有退出
2. 检查地址格式是否正确（http://192.168.x.x:8888）
3. 尝试在电脑上 ping 手机 IP 地址
4. 检查手机是否切换了网络

### Q: M3U8 视频播放失败？
A: 
1. 某些视频源可能有防盗链保护
2. 尝试使用系统播放器或复制地址
3. 检查浏览器控制台的错误信息

### Q: 视频播放卡顿？
A: 
1. 检查 WiFi 信号强度
2. 尝试靠近路由器
3. 关闭其他占用网络的应用
4. 使用 5GHz WiFi 频段（如果支持）

# 视频流程日志功能说明

## 功能介绍

我已经为你的应用添加了一个完整的视频流程日志系统，可以记录从视频嗅探到播放的每一步操作，方便你定位和修复问题。

## 主要特性

### 1. 可折叠的日志界面
- 每个视频播放会话都有独立的日志记录
- 点击标题可以展开/收起查看详细日志
- 界面简洁，不会显得杂乱

### 2. 长按复制功能
- **长按**整个日志卡片可以复制完整日志
- 或者点击右上角的**"复制"按钮**
- 复制后可以直接发给我，方便定位问题

### 3. 完整的流程记录
日志会记录以下阶段：
- 🔧 **初始化**：播放器启动
- 🔍 **资源嗅探**：浏览器嗅探到的视频链接
- 🔗 **链接解析**：解析视频播放地址
- 🌐 **网络请求**：HTTP请求和响应
- ▶️ **播放器初始化**：准备播放
- ⏳ **加载视频**：缓冲状态
- ✅ **开始播放**：播放、暂停等操作
- ❌ **播放错误**：错误信息和堆栈
- 📥 **下载**：视频下载过程

## 如何使用

### 查看日志
1. 打开应用
2. 进入**"设置"**页面
3. 找到**"视频流程日志"**选项（在"内置浏览器"下面）
4. 点击进入日志界面

### 复制日志
1. 在日志界面找到你想复制的会话
2. **长按**整个卡片，或点击右上角的**"复制"**按钮
3. 日志已复制到剪贴板
4. 可以粘贴到微信、QQ等发给我

### 清除日志
- 点击顶部的**"清除所有日志"**按钮
- 系统会自动保留最近10个会话

## 下一步：集成到现有代码

要让日志系统工作，需要在关键位置添加日志记录代码。我已经准备好了两个文件：

1. **VideoFlowLoggerIntegration.kt** - 查看这个文件了解如何在各个模块中集成
2. **VideoPlayerActivityLoggerPatch.kt** - 查看这个文件了解如何在播放器中集成

### 快速开始（最小集成）

只需在 `VideoPlayerActivity.kt` 中添加3处代码：

```kotlin
// 1. 在 onCreate() 开始处
VideoFlowLogger.startSession(videoTitle, videoUrl)

// 2. 在播放视频时
VideoFlowLogger.info(VideoFlowLogger.FlowStage.PLAYER_INIT, "开始播放", "URL: $url")

// 3. 在 onDestroy() 中
VideoFlowLogger.endSession()
```

这样就可以开始记录基本日志了！

## 注意事项

1. **隐私保护**：日志可能包含视频URL等信息，分享时请注意
2. **性能影响**：日志记录有轻微性能开销，但已优化到最小
3. **自动清理**：系统自动保留最近10个会话，旧日志会被清除

# 夜间模式测试指南

## 测试步骤

### 1. 安装应用
APK 位置：`app/build/outputs/apk/debug/app-arm64-v8a-debug.apk`

### 2. 打开应用并设置夜间模式

1. 打开"影视星球"应用
2. 点击底部导航栏的"设置"
3. 点击"更换主题色"
4. 在"夜间模式"卡片中，选择"深色模式"

### 3. 验证效果

选择"深色模式"后，应该立即看到以下变化：

#### 应该变成深色的元素：
- ✅ 页面背景：从白色变为深灰色 (#121212)
- ✅ 卡片背景：从白色变为深灰色 (#1E1E1E)
- ✅ 文字颜色：从黑色变为浅色 (#E0E0E0)
- ✅ 次要文字：从深灰变为浅灰 (#B0B0B0)
- ✅ 分割线：从浅灰变为深灰 (#2C2C2C)

#### 检查这些页面：
1. **首页**
   - 视频卡片背景应该是深灰色
   - 视频标题文字应该是白色
   - 轮播图卡片背景应该是深灰色
   
2. **设置页面**
   - 快捷入口卡片背景应该是深灰色
   - "我的收藏"等文字应该是白色
   - 设置项卡片背景应该是深灰色
   - 所有文字应该清晰可见

3. **历史页面**
   - 背景应该是深色
   - 卡片应该是深灰色

## 如果还是白色的

### 可能的原因：

1. **系统强制浅色模式**
   - 检查：设置 → 显示 → 深色主题
   - 如果系统设置为"浅色"，且应用选择"跟随系统"，则会显示浅色

2. **应用没有重启**
   - 完全关闭应用（从最近任务中划掉）
   - 重新打开应用

3. **缓存问题**
   - 在设置中清除应用数据
   - 重新打开应用并设置夜间模式

### 调试方法：

1. **检查当前夜间模式设置**
   ```bash
   adb shell "run-as com.tv.ball cat /data/data/com.tv.ball/shared_prefs/video_player_prefs.xml"
   ```
   应该看到 `<int name="night_mode" value="2" />` (2 = 深色模式)

2. **查看应用日志**
   ```bash
   adb logcat | grep -i "night\|theme\|mode"
   ```

3. **强制深色模式（测试用）**
   ```bash
   adb shell "cmd uimode night yes"
   ```

## 已知问题

1. 某些使用 `Theme.AppCompat.NoActionBar` 的 Activity 可能不支持夜间模式
   - VideoPlayerActivity
   - LocalVideoActivity
   - WebViewActivity
   - 等

2. 某些第三方库的 UI 组件可能不支持夜间模式

## 下一步优化

如果基本的夜间模式工作正常，但某些页面还有问题，可以：

1. 逐个检查和修复特定页面的布局文件
2. 为使用 `Theme.AppCompat.NoActionBar` 的 Activity 创建支持 DayNight 的主题
3. 检查自定义 View 和 Adapter 中的硬编码颜色

## 待修复问题

### 2. 剧集线路分组显示

**当前状态**：
- 剧集名称格式：`[线路1] 第1集`, `[线路1] 第2集`, `[线路2] 第1集`...
- UI显示：所有剧集在一个RecyclerView中，没有分组

**解决方案选项**：

#### 方案A：修改UI支持分组（推荐）
创建一个支持分组的Adapter，按线路名称分组显示：
```
线路1
  第1集  第2集  第3集  第4集
  第5集  第6集  第7集  第8集

线路2  
  第1集  第2集  第3集  第4集
  第5集  第6集  第7集  第8集
```

**需要修改的文件**：
1. `VideoDetailActivity.kt` - 添加分组逻辑
2. 创建新的 `GroupedEpisodeAdapter.kt`
3. 可能需要修改布局文件

#### 方案B：使用TabLayout切换线路（简单）
在详情页顶部添加Tab，每个Tab对应一个线路：
```
[线路1] [线路2] [线路3]
----------------------------
第1集  第2集  第3集  第4集
第5集  第6集  第7集  第8集
```

**需要修改的文件**：
1. `activity_video_detail.xml` - 添加TabLayout
2. `VideoDetailActivity.kt` - 添加Tab切换逻辑
3. 修改 `EpisodeAdapter` 过滤显示当前线路的剧集

#### 方案C：保持当前UI，优化显示（最简单）
在剧集按钮上显示完整名称 `[线路1] 第1集`，用户可以看到线路信息。

**优点**：无需修改代码
**缺点**：按钮文字较长，可能显示不全

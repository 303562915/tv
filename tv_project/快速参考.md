### 🎯 核心功能

#### 1. 查看视频信息
```
方法1: 播放器菜单 → 视频信息
方法2: 点击清晰度按钮（如"1080p"）
```

#### 2. 设置重复播放
```
播放器菜单 → 重复播放 → 选择模式
- 关闭：播放完毕后停止
- 单集循环：当前视频循环
- 列表循环：播放列表循环
```

#### 3. 调整画面比例
```
播放器菜单 → 画面比例 → 选择模式
- 自适应/16:9/4:3/铺满/放大
```

#### 4. 精确调节倍速
```
播放器菜单 → 播放倍速
- 滑动条：0.5x - 2.0x 精确调节
- 快捷按钮：0.5x/0.75x/1.0x/1.25x/1.5x/2.0x
```

### 🔧 技术细节

#### 清晰度等级
```kotlin
4K    - 2160p及以上
2K    - 1440p
1080p - 全高清
高清   - 720p
标清   - 480p
流畅   - 360p
低画质 - 360p以下
```

#### 重复播放模式
```kotlin
REPEAT_MODE_OFF - 关闭重复
REPEAT_MODE_ONE - 单集循环
REPEAT_MODE_ALL - 列表循环
```

# 多语言资源审计

`orchestrator/scripts/i18n_audit.py` 比对 `res/values/` 与 `res/values-<lang>/` 的字符串键。

```bash
python orchestrator/scripts/i18n_audit.py              # 审计 values-en
python orchestrator/scripts/i18n_audit.py --lang zh-rTW
python orchestrator/scripts/i18n_audit.py --strict     # 有缺失/多余时退出码 1
```

## 输出

- 基准与目标的键数量
- 缺失键（含它定义在哪个文件），并附一份可直接粘贴的 `<resources>` 模板
- 多余键（基准里没有，可能是拼写错或已经删除）

## 约定

- 新增字符串一律键名带模块前缀（`f0xx_`），减少跨模块撞名。
- 翻译文件只放被 `values/` 引用的键；多余键会让审计报错，这是故意的，避免留下僵尸文案。
- CI 里可以接 `--strict`，但要在翻译补齐之后再打开，否则会一直是红的。

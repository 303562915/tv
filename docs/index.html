安装

  1. 下载上面的 APK，用电视 / 盒子上的文件管理器安装。若被拦截，在系统设置里允许「安装未知应用」。
  2. 或者用 adb 远程安装：adb connect 192.168.1.50:5555 之后 adb install -r TVPlayer-latest-debug.apk。
  3. 打开 TV Player，选本地视频，或粘贴你自备的 HLS / MP4 直链开始播放。应用不内置任何内容。

常见问题

这个页面为什么要自己托管下载？

GitHub Releases 的下载地址在国内时常连不上，所以 APK 由 CI 同步到 Pages 这边做镜像；版本、体积、SHA-256 与 Releases 完全一致。

APK 是怎么构建的？可信吗？

由 GitHub Actions 在云端从本仓库源码构建、签名并上传，本页面与 APK 来自同一条流水线。你可以用上面的 SHA-256 与自己下载到的文件比对。

自带影视内容或视频源吗？

不带。应用不提供、不聚合、不分发任何影视内容，也没有内置源。播放内容由你自己提供：本地文件，或你自备的网络地址。

支持哪些 Android 版本与设备？

最低 Android 7.0（API 24）。面向 Android TV 与电视盒子，遥控器 D-Pad 操作优先；手机也能装，触摸同样可用。

为什么只发 arm64-v8a？

电视与盒子基本都是 64 位 ARM 芯片，只打一个 ABI 能显著减小安装包体积。32 位设备（armeabi-v7a / x86）装不上。

播放卡顿怎么办？

先换线路（多线路会自动测速），再确认网络；本地文件卡顿多半是编码过重，试试切换画面比例，或换兼容编码的版本。

仅发布 arm64-v8a 构建；应用不提供任何影视内容，使用后果由使用者自行承担。
